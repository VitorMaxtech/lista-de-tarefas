# My To-Do List

A web application developed to organize daily tasks, allowing users to add, complete, delete, and filter activities.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)

## Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Filter tasks by status: all, pending, and completed.
- Automatic task counter.
- Data persistence using `localStorage`.

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open the `index.html` file in your browser.

No dependencies need to be installed, and no server configuration is required.

## Tests

With Node.js 18 or later installed, run `npm test` in the project folder. The tests use Node's built-in runner (`node --test`), with no dependencies.
