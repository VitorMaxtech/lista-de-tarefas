# Minha Lista de Tarefas

Uma aplicação web desenvolvida para organizar tarefas diárias, permitindo adicionar, concluir, excluir e filtrar atividades

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (vanilla JS)

## Funcionalidades

- Adicionar novas tarefas.
- Marcar tarefas como concluídas.
- Excluir tarefas.
- Filtrar tarefas por status: todas, pendentes e concluídas.
- Contador automático de tarefas.
- Persistência dos dados utilizando localStorage.

#### Como executar

1. Clone este repositório
2. Abra a pasta do projeto.
3. Abra o arquivo index.html em seu navegador

Não é necessário instalar dependências ou configurar um servidor.

#### Testes

Com o Node.js 18 ou superior instalado, rode `npm test` na pasta do projeto. Os testes usam o executor nativo do Node (`node --test`), sem dependências.
